First I checked what the file is

```
file /tmp/excelsior11.cer
```

Tried reading it as DER Certificate:

```
openssl x509 -inform DER \
-in /tmp/excelsior11.cer \
-noout \
-subject \
-issuer \
-serial \
-dates \
-fingerprint \
-sha256
```

checked whether TLS can be done on LDAP (meaning can we connect on port 636)

```
timeout 10 openssl s_client \
-connect awsmasterdc1.master.hmkad.hallmark.com:636 \
-servername awsmasterdc1.master.hmkad.hallmark.com \
-showcerts </dev/null
```

it is a DER/binary file, so made a PEM copy

```
openssl x509 \
-inform DER \
-in /tmp/excelsior11.cer \
-out /tmp/excelsior11.pem
```
